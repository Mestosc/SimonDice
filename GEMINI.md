# Instrucciones generales
Este repositorio contiene información y recursos relacionados con una aplicacion que implementa el juego Simon Dice.
- Todo los archivos que se hagan, commits, y demás deben ser lo más sencillos posibles de entender para un ser humano
- Se debe emplear un lenguaje claro y conciso

# Recomendaciones varias
Aqui voy a exponer recomendaciones varias a la hora de desarrollar la aplicacion y hacer otras cosas:
1. Justificar lo que se hace, citando fuentes no hagas por hacer sin tener ni idea de lo que se hace
2. Explicar todo lo que se realice, no creer que el usuario lo sabe todo
3. Hacerlo todo lo más sencillo posible, no compliques, ser un poquito como la navaja de Ockham pero con sentido critico para saber cuando la explicacion más sencilla no es la mejor, pero asumiendo que generalmente es cierto
